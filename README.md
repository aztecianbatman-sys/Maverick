# Maverick

**Your friendly friend for your device.**

Maverick is a Windows-first security project with two desktop experiences:

- **Maverick Security** — the protection-focused application.
- **Maverick AI** — the same protection capabilities with a BYOK AI investigation/chat interface.

## Development rules

1. Build one phase at a time.
2. No fake detections, fake scans, fake security claims, or placeholder functionality presented as real.
3. Keep protection independent from the AI provider.
4. Store Maverick's local activity data on the device.
5. Never commit API keys, credentials, signing secrets, or private test material.

## Current phase

**Phase 0 — Architecture**

The current repository contains the initial architecture/scaffolding only. UI, model browsing, BYOK provider integrations, and security functionality will be implemented in their designated phases.
